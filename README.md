# TMob

An application built as a test assignment demonstrating modern Android development approaches, reactive streams, and a robust architecture.

---

## 🛠 Tech Stack

| Technology | Purpose |
| :--- | :--- |
| **Kotlin** | Programming language |
| **Coroutines & Flow** | Asynchronous operations and reactive streams |
| **MVI** | Architectural pattern (Model-View-Intent) |
| **Jetpack Compose** | Declarative UI |
| **Decompose** | Navigation and component lifecycle management |
| **Room** | Local database |
| **Hilt** | Dependency Injection |
| **Retrofit** | Networking (REST API) |
